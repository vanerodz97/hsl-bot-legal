This Privacy Policy explains what data the Sniping League Stats Bot (the "Bot") processes and stores when it's added to a Discord server, and why.

1. What the Bot processes

2. No third-party data sharing

Screenshots are read using on-device optical character recognition (OCR) running on the Bot's own server. No image or extracted data is sent to any external API or third-party service for processing.

3. Where data is stored

Stats data is stored in a local data file on the server the Bot runs on. It is not sold, shared, or used for any purpose beyond displaying the dashboard in the Discord server that generated it.

4. Data deletion

Removing the Bot from a server does not automatically erase its stored data file entry for that server. To request deletion of a server's stored dashboard data, contact [your contact email or Discord server invite link].

5. Children's privacy

The Bot is not directed at children and does not knowingly collect data from users below the minimum age required to use Discord in their region, consistent with Discord's Terms of Service.

6. Changes to this policy

This Privacy Policy may be updated from time to time. Material changes will be reflected by an updated effective date above.
